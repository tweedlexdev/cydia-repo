# Tweedlex Cydia Repository

Official Cydia repository by Tweedlex for iOS 6.1.3 and legacy iOS devices.

## 📲 Add to Cydia
To add this repository to your device:
1. Open **Cydia** -> **Manage** -> **Sources**
2. Tap **Edit** -> **Add**
3. Enter URL: `https://tweedlexdev.github.io/cydia-repo/`
